# 🎂 Happy Birthday Apah

Un mini-site interactif créé pour **Apah | 悪魔 (@aa6a49)**.

## Contenu
- Animation d’accueil, confettis et interactions
- Photo de profil fournie par le créateur
- Audio `assets/joyeux-anniversaire.mp3` — la lecture démarre après un clic (règles des navigateurs)
- Site statique, aucun backend requis

## Mise en ligne GitHub Pages
1. Créer un dépôt public `Happy-Birthday-Apah` sur GitHub.
2. Mettre tous les fichiers du dossier **à la racine** du dépôt.
3. Ouvrir **Settings → Pages → Build and deployment**.
4. Choisir **Deploy from a branch**, `main`, `/ (root)` puis **Save**.
5. Une fois le déploiement terminé, ouvrir `https://itztov4r.github.io/Happy-Birthday-Apah/`.

Note : publier de la musique sur un site public suppose les droits de diffusion appropriés.
