# 🎂 Happy Birthday Apah

Site anniversaire animé pour Apah | 悪魔 (@aa6a49), avec avatar, cadeaux interactifs, confettis et musique.

**Musique :** le fichier MP3 original a été réparti sans perte en 22 petits segments binaires dans `assets/audio/`. Le navigateur les charge et les assemble automatiquement. La musique débute après le clic de l'utilisateur si le navigateur l'autorise.

**Déploiement :** GitHub Pages → Settings → Pages → Source Deploy from a branch → main → /(root).

La diffusion publique d'un enregistrement musical requiert les autorisations correspondantes.
